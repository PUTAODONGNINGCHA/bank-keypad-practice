# 银行小键盘录入练习

纯前端单文件练习工具，专练银行柜面数字小键盘（数字键盘区）的盲打速度与准确率。
零依赖、零构建，打开 `index.html` 即用。

**在线访问：** https://putaodongningcha.github.io/bank-keypad-practice/

## 三种模式

| 模式 | 说明 |
| --- | --- |
| 数字速打 | 连续输入随机数字，每行 20 位；题长可选 60 / 120 / 200 / 300 / 500 / 700 / 1000 位 |
| 金额录入 | 逐笔录入金额，每笔输完按回车确认，整数位 1~24 位随机 |
| 传票翻打 | 24 笔长短不一的金额连打，小数点对齐，练实战节奏 |

## 功能特点

- **亮 / 暗色调切换**：标题栏右侧按钮一键切换，选择记在本地，下次打开保持。默认暗色（与既有观感一致），首屏渲染前即定好主题，不会先闪一帧再变色。
- **按错红闪**：输错时当前字符原地闪一下红色（保持约 200ms 再淡回），随后自动恢复成待输入的蓝色光标——继续停在原位等你重输，不前进、也不把红留在屏幕上。传票 / 金额模式下「一笔已输完、等回车时按错键」，改闪「按回车确认」这行提示。反馈全部落在题面上，控制栏不再显示任何文字。
- **小数点分列对齐**：按行内最大小数位数固定尾部占位宽度，小数位数不同的各行小数点仍落在同一列，练的是真反应而不是找小数点。
- **废题过滤**：自动重掷全同号（8888）、等步长连号（1234、2468）、回文（12321）这类有规律的数字串。
- **仅用小键盘**：开启后主键盘数字键被拦截（只响一声错误音，不计入击键总数），强制使用数字键盘区。
- **不挑 NumLock 状态**：按键按物理位置（`KeyboardEvent.code`）判定，NumLock 关闭时小键盘照样能开始练习、正常计分。
- **长题面自动跟行**：速打位数超出可视区时，当前行恒定停在可视区上 1/3 处匀速上移（提词器式），进度栏同步显示「第 N / M 行」，不会打到一半看不见自己打到哪。
- **平板 / 手机适配**：题面字号按视口连续缩放（每行 20 位在任何宽度下都不横向溢出），练习区高度随可视区收缩，控件在触控设备上抬到 44px 触控高度，并适配刘海屏安全区。
- **iPad 可直接用**：点一下练习区即可调出数字键盘（`inputmode=numeric`），触控设备默认不勾选「仅用小键盘」——否则软键盘发出的 `Digit` 键会被全部拦下。
- **键击音效**：机械键盘 / 清脆叮 / 木质轻叩三种音色，用振荡器 + 白噪声瞬态合成，可关闭。
- **实时统计**：用时、准确率、键/分钟、击键总数、错误次数。

## 快捷键

- 按**任意键**开始计时
- **Tab**：重新开始本轮
- **Enter**：金额/传票模式下确认当前一笔

## 本地使用

直接双击 `index.html` 用浏览器打开即可，无需服务器。

**iPad / 平板**：打开后轻点练习区即可调出数字键盘（走 `inputmode=numeric`）。触控设备默认不勾选「仅用小键盘」；若你外接了数字小键盘并想按严格模式练，再手动勾上即可。

## 修复记录

- **按任意键开始后立刻退回「准备就绪」**：按钮（「重新开始」/模式页签）点过之后仍留着键盘焦点，此时按**空格**开始，浏览器会在 keyup 把焦点按钮当成被再次点击 → 触发 `click` → 重置练习，表现为「刚进入打字状态一瞬间又退回去」。数字键因为会走 `preventDefault()` 而侥幸没事，空格返回 `null` 提前 `return`，是唯一的漏网键。现已在开始练习时收回按钮/下拉框焦点并拦掉该次按键的默认行为。
- **NumLock 关闭时只有回车能开始**：开始键判定原本用 `e.key`，而 NumLock 关闭时小键盘数字键的 `e.key` 是 `Home`/`ArrowUp`/`End` 等，正好撞上浏览器的功能键黑名单（7=Home、8=ArrowUp、1=End…），于是除回车外全都无法开始。现改为按 `e.code` 优先放行小键盘。
- **计时器泄漏**：`reset()` 直接整体替换状态对象，上一轮的 `setInterval` 句柄随之丢失、无法清理，多轮重启后会有多个残留定时器持续刷新统计（结束后用时还在往上跳）。现于 `reset()` / `finish()` 中先清理并置空句柄。
- **每次开始答题页面往下跳**：练习区 `.stage` 用的是 `min-height`，高度由内容撑开——准备页 320px，开始后速打变 424px、传票变 508px，于是下面的统计栏/控制栏整体被顶下去（速打 +104px、传票 +188px）。现改为固定高度，准备页与答题页严格等高，超长题面交给内部滚动。
- **空格导致整页滚动**：空格的浏览器默认行为是「向下翻页」，而本应用把空格当开始键，于是开始答题时整页会往下滚一屏（矮窗口下实测 161px）。现除复选框外一律拦掉空格的默认行为。
- **长位数题面被裁切**：`.flow` 是 flex 子项且默认 `flex-shrink:1`，300 位题面会被压扁溢出、既不滚动也看不全；同时 `#stage` 容器默认 `min-height:auto` 拒绝收缩，使 `.flowbox` 的 `overflow` 失效。现补 `flex:none` 与 `#stage{flex:1;min-height:0}`，超出部分正常内部滚动。
- **打一行、其他行跟着变绿**：金额录入 / 传票翻打里，行着色原本用同一个 `S.pos` 当作「已输入长度」，未开始的行也被套用 → 当前行输 6 位，后面每一行的前 6 位同时变绿（24 笔时实测 138 个字符被误染）。现按三种行分开处理：已完成行整行绿、当前行只绿已输入前缀、未开始的行不着色。
- **长题面打到一半看不见光标行**（随速打位数扩充至 1000 位一并修复）：速打每次击键都整体重建 `#stage`，新建容器的 `scrollTop` 归 0，于是题面一旦超过可视高度（200 位约 11 行起）正在打的那一行就被永久顶到视口外，越打越盲。原 300 位已存在此问题，且新增 500 / 700 / 1000 位后完全不可用。现补 `scrollFlowToCur()`：当前行恒定停在可视区上 1/3 处（提词器式匀速上移）。整轮 1000 位实测光标行**不可见次数 0**，`scrollTop` 按行单调推进（0→45→103→…→2464→2498），末行未被裁；未溢出的短题面（120 位）`scrollTop` 恒为 0，维持原有居中观感。
- **iPad 上打不出数字**：iOS / iPadOS 只在输入类元素获得焦点时才弹软键盘，原先只有 `keydown` 监听，点屏幕毫无反应。现加了一个隐形输入框（`inputmode=numeric`），点练习区即聚焦它、弹出数字键盘；同时软键盘的数字键上报的 `code` 是 `Digit1` 而不是 `Numpad1`，若默认勾着「仅用小键盘」会被逐个拦下，故触控设备默认取消勾选。此外补了 `e.key` 兜底（部分浏览器软键盘只给 `key` 不给 `code`），并区分 `,` 与 `.` 两种小数点上报方式。
- **窄屏横向溢出**：题面每行固定 20 位且不换行，字号固定 32px 时在手机宽度下会横向溢出；练习区固定 460px、控件高度 28~33px 在平板上也不合适。现把练习区高度、内边距、题面字号与字距抽成 CSS 令牌，窄屏只改令牌；字号按视口连续缩放（`clamp(14px,4.2vw,32px)`，实测「最宽行墨迹 = 15.8×字号 + 20×字距」），粗指针设备把控件抬到 44px。实测 390 / 768 / 820 / 1024 / 1246px 五档均无横向溢出、页面无需竖向滚动、小数点列取值数恒为 1；桌面档的区块几何与改造前逐项相同（header 33、stage 顶 64 高 460、stats 顶 537、bar 顶 625），即版式零影响。
- **按错时没有即时反馈**：原先按错只有统计里的错误次数 +1，另加底部一行小字提示（「错！应为 七，食指」，该文字提示已在后续版本整体移除，见末条），而题面上光标位仍显示为待输入态——视觉上分不出「刚按错了」和「还没按」，长题面下更注意不到底部那行字。现补 `errflash` 动画：判错时只记一个「哪一位错了」的标记，渲染时给该字符挂 `.err`，播一遍 500ms 动画（前 200ms 保持红、再淡回蓝光标），无需正确输入即可自动复原。两个实现前提写在这里备查：① 动画能「只播一次」靠的是题面每次击键整块重建，元素新建时 CSS 动画天然从 0% 起播；② 因此该标记必须在**下一次击键进入判分之前**清空，否则重建会把动画重播一遍、还会串行到下一笔（实测按回车进入下一笔时新行的 `.chk` 会跟着闪）。全程不改 `S.pos`，原有的「停在原位等重输」口径不变；1000 位题面第 200 位按错实测 `scrollTop` 不受影响、光标行仍在框内 127px 处。另在 `prefers-reduced-motion:reduce` 下降级为静态红（保留反馈、去掉动画）。
- **移除控制栏文字提示**：判错时原会在控制栏显示一行黄色小字（「错！应为 七，食指」），与同位置的「请使用数字小键盘」「本笔已输入完，请按回车确认」共用同一个提示位（`#msg`）。这三类反馈现在都由题面承载——判错与「等回车时按错」是题面内对应字符/提示行闪红，主键盘数字被拦是错误音效——文字属重复信息，故整体移除：`#msg` 元素、`flash()` 及其 1.6s 定时器、`cueText()` 与仅供其使用的 `FINGER` / `SPEAK` 指法映射表一并删除（`--amber` 令牌保留在调色板中）。实测按错后 `pos` 仍停在原位、错误数 +1、红闪元素数 1、动画名 `errflash`；重输正确后 `pos` +1、错误标记残留 0；控制栏文字残留 0；几何与移除前逐项一致（header 高 33、stage 顶 64 高 460、stats 顶 537、bar 顶 625 高 54），小数点列取值数仍为 1。
